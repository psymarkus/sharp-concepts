# SHARP Concepts Ontology

The SHARP Concepts Ontology provides a SKOS-based vocabulary of concepts related to adaptive learning, instructional support, learning processes, educational interventions, and related domains.

## Resources

Concept Index:
https://w3id.org/sharp

Ontology:
https://w3id.org/sharp/ontology

Concept Scheme:
https://w3id.org/sharp/scheme/SHARP
