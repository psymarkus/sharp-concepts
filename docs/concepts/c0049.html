Definition

A task describes a type of problem that needs to be mastered in a professional field. A task description includes representational features of task approximations in learning settings. Defining a task includes specifying measurable criteria for successful task performance. A task description may include "blanks" to be filled in that allow to span a range of different instantiations (= cases).
