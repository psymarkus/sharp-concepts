Preferred label

Cognitive learning prerequisites

Alternative labels

No alternative labels available.

Definition

Cognitive learning prerequisites refer to relatively stable general cognitive abilites possessed by learners, which learners bring to a learning situation and that influence learning processes and learning outcomes.
