Learning process scaffolding

Identifier

c0023

Preferred label

Learning process scaffolding

Alternative labels

No alternative labels available.

Definition

Learning process scaffolding enhances learners' engagement in an effective learning process by offering additional instructional support beyond the core learning task's instruction. Learning process scaffolding encompasses various forms: worked and modeling examples for exemplifying appropriate task processing o prompts and hints for directing attention to specific task elements (e.g., cognitive and metacognitive prompts) ; scripts and roles for defining responsibilities and detailing task steps (e.g., collaboration scripts) ; reflection phases and for task evaluation (e.g., identifying goals and planning next steps) and self-assessment ; cueing ; Sharing and eliciting evidence and hypotheses
